# Wiki de Notebookvibes

## Mapa

1. `ARCHITECTURE.md`: componentes y flujos de confianza.
2. `PROFILE.md`: identidad del perfil, skills y configuración portable.
3. `SECURITY.md`: exclusiones, secretos, privacidad y gates de aprobación.
4. `OPERATIONS.md`: pruebas, ejecución local y despliegue.
5. `EXPORT_POLICY.md`: qué se exportó y qué se excluyó del perfil vivo.
6. `../INTEGRATIONS_ANALYSIS.md`: priorización funcional de integraciones.
7. `../ZERNIO_INTEGRATION.md`: diseño del módulo social.

## Objetivo

Notebookvibes convierte preguntas abiertas en evidencia verificable y reutilizable. El perfil investiga, contrasta y sintetiza; Open Notebook conserva las fuentes aprobadas; la Mini App conecta proveedores sin exponer sus credenciales; los dashboards presentan resultados distinguiendo observación e inferencia.
